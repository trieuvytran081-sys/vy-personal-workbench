# Vy’s Workbench

A responsive, single-file personal workbench template. The complete page, styles, and browser-side interactions are in [`index.html`](./index.html); it has no build step or external dependencies.

## Make your own copy

1. Fork this repository.
2. Edit the `workbench` object in `index.html` with your own display name, greeting, cards, modules, navigation, quick entries, and actions.
3. To publish your copy, open **Settings → Pages** in your fork and deploy from the `main` branch, using the repository root.

The quick input adds entries for the current browser session. This static page has no server, account system, or shared live activity feed. Visitors can see the deployed page and can fork the source to make a separate workbench.

## Public page note

If this repository or its Pages site is public, anyone with the link can read the workbench details included in `index.html`. Review and change those details before publishing a personal copy.
