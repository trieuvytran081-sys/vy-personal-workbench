A SMALL, CAREFUL LOOP

From source to signal.

Every brief starts with an authorized source and ends with a draft a person can review.

01 / RECEIVE

Set the scope

Capture the source, request, context, and useful parameters.

02 / VALIDATE

Check access

Confirm the source is readable and the request fits the task.

03 / REVIEW

Find the signal

Review the selected material and keep evidence connected to themes.

04 / RETURN

Draft for review

Share scope, summary, confidence, open questions, and a next step.

EVIDENCE BEFORE INTERPRETATION

Standards that keep it honest.

One source can suggest a pattern. It cannot prove what an entire market is doing.

↗

Stay source-bound

Report patterns from the supplied material, with scope made clear.

◎

Show the evidence

Use timestamps, quotations, or examples only when they are available.

?

Name uncertainty

Flag unclear passages, conflicting evidence, and open questions.

✓

Leave room for review

Return a draft and a useful next step for the person reviewing it.
